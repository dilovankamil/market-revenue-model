# UX v2 changes

This pass responds to review of the first published SI-053 Strategic Model.

- Globe uses MapLibre globe styling with explicit sky/fog treatment rather than the generic map style.
- Global Opportunity has Play/Pause playback from model start through the forecast horizon, slow globe rotation, temporal market activation and a prominent cumulative-revenue card.
- Revenue bars animate smoothly when indications, markets or commercial assumptions change.
- Revenue bars are stacked and can be colored by indication (default) or region.
- Clinical-development marks beneath early forecast years are explicitly labelled as annotations and explained below the chart.
- Commercial Model defaults to a simplified regional control surface; the previous detailed country/portfolio controls remain available behind `+ Advanced controls`.
